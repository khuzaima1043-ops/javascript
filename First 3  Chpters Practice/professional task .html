Grocery Store Billing System

Grocery Store Billing System ek simple JavaScript-based system hai jo grocery items ki prices ko manage aur customer ka total bill calculate karne ke liye banaya gaya hai. Is system mein user apni required grocery items select karta hai, unki prices automatically total bill mein add hoti hain, aur total amount ke according discount calculate hota hai. Project mein JavaScript ke objects, functions, conditions, switch-case, loops, operators, ternary operator, prompt aur alert jaise concepts ko practical way mein use kiya gaya hai. Is project ka purpose programming logic aur problem-solving skills ko improve karna hai.
