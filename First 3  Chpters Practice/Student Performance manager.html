Student Performance Manager

Student Performance Manager ek aisa system hai jo students ke marks ko manage aur analyze karne ke liye banaya gaya hai. Ismein student ke different subjects ke marks ko process karke uska average, grade aur pass ya fail status calculate kiya jayega. Is project ka purpose JavaScript ke basic concepts ko ek practical system mein use karna aur programming logic aur problem-solving skills ko improve karna hai.
